# Angel Alcantara – Agile Method Repository

Welcome to my personal workspace for the **Tecmilenio Agile Method** course.

## 📌 Purpose
This repo tracks my progress, reflections, and deliverables as I learn and apply Agile principles, Scrum practices, and continuous-improvement techniques.

## 📁 Structure
- `/sprints/` – Sprint retrospectives, velocity charts, burndown logs  
- `/product/` – Product vision, user-story map, backlog snapshots  
- `/ceremonies/` – Meeting notes for Sprint Planning, Daily Scrum, Review & Retro  
- `/evidence/` – Screenshots, Jira exports, Kanban board photos, Git history  
- `/reflections/` – Personal learning journal (what I tried, what failed, what I’ll change)  

## 🎯 Learning Goals
1. Internalize the 4 Agile values & 12 principles  
2. Run a full Scrum cycle (plan-build-measure-learn) at least twice  
3. Improve team collaboration by experimenting with WIP limits and pair-work  
4. Deliver a potentially-shippable increment every sprint
