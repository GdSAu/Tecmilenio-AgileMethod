# Proyecto Final Mendix | Metodologías Ágiles

## 💡 Sobre el Proyecto
Este proyecto fue desarrollado como parte del curso de Mendix en la materia de **Metodologías Ágiles** en Tecmilenio. La solución utiliza tecnología **Low-Code** para resolver problemas de negocio reales, enfocándose en la **rapidez de entrega** y la **adaptabilidad** a los cambios.

La aplicación demuestra la potencia de la abstracción visual para administrar registros, visualizar datos en tiempo real y automatizar flujos de trabajo complejos sin la necesidad de código tradicional.

## ✨ Características y Funcionalidades

| Funcionalidad | Descripción |
| :---- | :---- |
| **⚡ Gestión Rápida (CRUD)** | Altas, bajas y cambios de información en segundos. |
| **🤖 Automatización** | Procesos de negocio optimizados mediante **Microflows**. |
| **✅ Calidad de Datos** | Reglas de validación integradas en todos los formularios. |
| **🔒 Seguridad Robusta** | Configuración a nivel de proyecto con roles definidos (Admin vs Usuario). |
| **📱 Diseño Adaptativo** | Interfaz construida con Atlas UI, funcional en móviles y escritorio. |
| **📊 Dashboard** | Visualización gráfica de los datos ingresados para la toma de decisiones. |

## 🛠️ Stack Tecnológico

Este proyecto aprovecha la arquitectura visual de Mendix y principios ágiles:

* **Core:** Mendix Studio Pro
* **Lógica de Negocio:** Microflows & Nanoflows
* **Base de Datos:** Mendix Built-in Database (HSQLDB / PostgreSQL)
* **UI Framework:** Atlas UI (basado en Bootstrap)
* **Metodología:** Scrum (Sprints de 1 semana)

## 🚀 Cómo ejecutar este proyecto

Para visualizar el código fuente, la lógica del modelo de dominio y los microflows:

1. **Clona** este repositorio o descarga el archivo `.mpk`.
2. Abre **Mendix Studio Pro** (Versión 9.x o superior).
3. Selecciona **"Open App"** y busca el archivo `.mpr` dentro de la carpeta `Rodrigo_Perez`.
4. Presiona **Run Locally** (F5) para desplegar la aplicación en tu servidor local.
